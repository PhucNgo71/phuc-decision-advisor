# Learning Imports

Imported knowledge is stored in `data/learning-imports.json`. Each source is reviewed before it can affect advice.

## Import rules

1. Preserve the source URL, title and import date.
2. Classify every record as Fact, Current Preference, Experience, Judgment, Hard Rule or Temporary Context.
3. Mark whether the record has direct, contextual or no effect on advice.
4. Keep conflicting ideas as separate records; do not silently choose one.
5. Do not treat software setup, access errors or deployment history as business knowledge.
6. Deduplicate a new record against existing learning before adding it.
7. A preference becomes a Hard Rule only when the user explicitly confirms it.
