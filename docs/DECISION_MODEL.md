# Decision Model v0.1

## Start with Win Objective

A project is not simply Win/Lose. Supported objectives:
- Must Win
- Targeted Scope Win
- Defensive Win
- Partial / Beachhead Win
- Profit-led
- Reference-led

Multiple objectives may coexist with different priorities.

## Reasoning dimensions

- Customer Brain
- Relationship & Power Brain
- Competition Brain
- Product & Portfolio Brain
- Commercial Brain
- Execution Brain
- Strategic Context

## Required Advisor output

Situation → Win Objective → Key Signals → Conflicts → Scenarios → Trade-offs → Risks → Unknowns → Recommended Direction → What Could Change My Advice → Confidence.

## Knowledge classification

Every new training input should be tagged as one of:
- Fact
- Current Preference
- Experience
- Judgment
- Hard Rule
- Temporary Context

Do not turn preferences or historical patterns into hard rules without explicit confirmation.
